# Lions Club Pro

Professional Lions Club software — first club: **Lions Club Gwalior Maitri**.  
Architecture is multi-club ready (commercial).

## Stack
Flutter · Mac / Android / Windows

## V1 Foundation includes
- Role-based entry (President, Secretary, Treasurer, VPs, Board, Member…)
- 14 modules from your spec (Dashboard → AI → Officers)
- Module hubs ready to expand into ~40–50 screens one-by-one
- Lions purple & gold theme

## Run
```bash
cd /Users/raghuwansh/lions_club_pro
flutter pub get
flutter run -d macos
```
